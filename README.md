## 🚀 Featured Project

### 🛡️ [Agent Permission Linter](https://github.com/Shrebibelagur/agent-permission-linter)

An open-source, read-only CLI that checks whether an AI agent holds more Microsoft Entra access than its MCP tools need.

- 7 rules: over-permissioned agents, missing ownership, long-lived secrets, missing justifications, excessive tool capability, unapproved auto-approve flags
- Reports in **Markdown, JSON and SARIF** (plugs into GitHub code scanning)
- Never writes to Entra and never contacts an MCP server
- Pseudonymised identifiers so shared reports don't leak tenant IDs

```bash
pip install agent-permission-linter
```
